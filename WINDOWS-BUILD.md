# Building SaiLang 0.9.9 for Windows on GitHub

1. Create a repository on github.com and upload the contents of this folder (keep `.github`).
2. Open the **Actions** tab, choose **build-windows**, then **Run workflow**.
3. When it finishes, download the artifact **SaiLang-0.9.9-windows**. It contains `SaiLang-v0.9.9-windows-x64.zip` with `sai.exe` and `SaiLang-IDLE.exe`.
